## 비교 및 결론

```
Optimal(13) < FIFO(17) < LRU(18)
```

- **Optimal**은 미래 참조 정보를 알고 있다는 가정 하의 이론적 최솟값이므로 실제 구현 불가능. 다른 알고리즘의 성능 비교 기준(하한선)으로 활용.
- **FIFO**는 구현이 단순하지만 **Belady의 이상 현상**(프레임 수 증가 시 폴트 증가)이 발생할 수 있음.
- **LRU**는 실제로 가장 많이 사용되는 근사 알고리즘이나, 이 참조열에서는 FIFO보다 오히려 폴트가 많음 (참조열 특성에 따라 역전 가능).
